# AutoTax Web — Public deployment assets

Đây là kho **phát hành website AutoTax** tại https://tendoodn.github.io/hddv/.

- Kho phát triển chính: `tendoodn/tax` (**Private**). Mã nguồn server, ứng dụng, SQL migrations và kiểm thử mới được quản lý tại đó.
- Kho `hddv` chỉ chứa các tệp HTML, CSS, JavaScript, SVG và font **phải được trình duyệt tải về** để website hoạt động. Không nên gửi source backend, khóa ký, file cấu hình bí mật hoặc bộ cài vào kho này.
- Bộ cài ZIP/CRX chỉ được phát hành tại [Google Drive AutoTax](https://drive.google.com/drive/folders/1q8l5pDqb0UzxFF2ma7Nm6KQyGX9UB0WF), giữ bản mới nhất và bản 3.3.6 gốc.

**Lưu ý:** JavaScript chạy trong trình duyệt luôn có thể được xem/copy. Ngoài ra, mã nguồn từng công khai ở các commit cũ có thể còn trong lịch sử Git, cache hoặc fork; chuyển sang private không thu hồi được những bản sao đã tồn tại.
